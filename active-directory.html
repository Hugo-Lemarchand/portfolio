Gestion des comptes et groupes Active Directory

Création, organisation et administration des utilisateurs et groupes dans un domaine Windows Server

Hugo Lemarchand · Ensitech · Session 2026

Présentation

Active Directory (AD) est l'annuaire centralisé de Microsoft, intégré à Windows Server. Il permet de gérer l'ensemble des utilisateurs, ordinateurs, groupes et ressources d'un domaine depuis un point unique.

La gestion des comptes et des groupes est au cœur de l'administration AD : elle conditionne les droits d'accès aux ressources, les stratégies de groupe (GPO) et la sécurité globale du SI.

Concepts clés

Objets AD principaux
  • Utilisateur – compte nominatif d'une personne
  • Groupe – ensemble d'utilisateurs/objets
  • Ordinateur – machine membre du domaine
  • UO (OU) – Unité d'Organisation, dossier logique
Types de groupes
  • Sécurité – gestion des droits d'accès
  • Distribution – listes de diffusion e-mail
  • Local domaine – droits sur ressources locales
  • Global – regroupe utilisateurs du domaine
  • Universel – multi-domaines (forêt)

Gestion graphique – MMC / ADUC

1

Ouvrir la console Active Directory

Via le Gestionnaire de serveur ou directement par Exécuter :

dsa.msc

La console Utilisateurs et ordinateurs Active Directory s'ouvre. On y retrouve l'arborescence du domaine avec les conteneurs par défaut (Builtin, Computers, Users…).

Console ADUC – domaine stadium.company.com avec les conteneurs par défaut

2

Créer une Unité d'Organisation (OU)

Les OU permettent d'organiser logiquement les objets (par site, service, fonction) et d'y appliquer des GPO ciblées.

  • Clic droit sur le domaine → Nouveau → Unité d'organisation
  • Nommer l'OU (ex : Direction, Informatique, RH)
  • Cocher « Protéger contre la suppression accidentelle »

Exemple d'arborescence AD : OU DC-STADIUMCOMPANY avec sous-OU et utilisateurs du domaine

💡 Bonne pratique Structurer les OU par département métier plutôt que par type d'objet. Ex : DC-STADIUMCOMPANY > Utilisateurs du domaine.
3

Créer un compte utilisateur

  • Naviguer dans l'OU cible
  • Clic droit → Nouveau → Utilisateur
  • Renseigner : Prénom, Nom, Nom d'ouverture de session
  • Définir le mot de passe et les options de politique
