Migration Domaine vers Intune

Active Directory → Microsoft Entra ID + Microsoft Intune

Hugo Lemarchand · Ensitech · Session 2026

Présentation

Ce projet décrit la procédure de migration des postes utilisateurs gérés par un domaine Active Directory on-premise vers une gestion cloud avec Microsoft Entra ID (ex-Azure AD) et Microsoft Intune (MDM).

J'ai appliqué la solution mise en place par mon manager pour faire basculer les utilisateurs du domaine vers Intune. Cette procédure couvre l'ensemble du processus : désinstallation des agents, sortie du domaine, jonction Entra ID, migration du profil utilisateur et vérifications finales.

Phase 1 – Préparation du poste

1

Sauvegarde des données utilisateur

Avant toute intervention, vérifier et sauvegarder les données de l'utilisateur :

  • Favoris du navigateur Chrome
  • Fichiers synchronisés sur OneDrive
💡 ConseilS'assurer que OneDrive est bien synchronisé et que les favoris Chrome sont exportés ou sauvegardés avant de commencer.
2

Désactivation du PIN CyberArk

Se connecter en tant qu'Admin CyberArk et désactiver le PIN pour permettre les opérations suivantes sans blocage d'authentification.

3

Exécution des politiques Automox

Depuis la console Automox, lancer les trois politiques dans l'ordre suivant :

  1. Exécuter : EXN uninstall Netskope Windows
  2. Exécuter : EXN Intune Copy Software
  3. Exécuter : EXN Intune Add Local User to Machine
⚠️ Si Netskope ne se désinstalle pas via Automox Aller dans Programmes et fonctionnalités et désinstaller manuellement avec le mot de passe : L3xRNA4Arv-mE*t6
4

Vérifications post-désinstallation

  • Confirmer que Netskope est bien désinstallé
  • Vérifier l'existence du dossier C:\Intune

Phase 2 – Configuration locale et sortie du domaine

5

Ajout au groupe Administrateurs

Ouvrir la Gestion de l'ordinateur en tant qu'administrateur, puis :

  1. Aller dans : Groupes → Administrateurs → Propriétés
  2. Ajouter l'utilisateur : magic
  3. Cliquer sur Appliquer → OK
6

Connexion avec l'utilisateur local Magic

Se déconnecter du compte domaine et se reconnecter avec le compte local créé :

  • Login : .\Magic
  • Mot de passe : We-n33d-to-migrate-FR
7

Sortie du domaine Active Directory

Depuis les propriétés système, quitter le domaine et rejoindre un groupe de travail :

  1. Groupe de travail : WORKGROUP
  2. Valider avec les identifiants : .\Magic
  3. Redémarrer la machine

Phase 3 – Jonction à Entra ID et migration du profil

8

Liaison à Entra ID (Azure AD)

Depuis la session du compte local Magic, rejoindre Entra ID :

  1. Aller dans : Paramètres → Accès professionnel ou scolaire → Se connecter
  2. Cliquer sur : Joindre cet appareil à Entra ID
  3. Entrer les identifiants Office 365 de l'utilisateur
  4. Cliquer sur Joindre, puis Terminé
9

Changer d'utilisateur

Après la jonction à Entra ID, changer d'utilisateur (sans redémarrer) pour passer au compte Office 365 créé, avant de lancer la migration de profil.

10

Migration du profil utilisateur avec Profwiz

Dans le dossier C:\Intune, lancer Profwiz (version 2) :

  • Chemin utilisateur : C:\Users\NomUtilisateur
💡 En cas de double profil Windows Vérifier quel dossier contient le plus de données et utiliser ce chemin dans Profwiz.

Options à configurer dans Profwiz :

  • ❌ Décocher : Join Domain
  • ✅ Cocher : Azure AD
  • ❌ Décocher : Set as default login

Entrer l'adresse email Office 365 de l'utilisateur, puis terminer l'assistant.

11

Redémarrer la machine

Redémarrer le poste pour finaliser la migration du profil et appliquer les paramètres Entra ID.

Phase 4 – Vérifications et finalisation

12

Vérifications finales

Après redémarrage, vérifier le bon fonctionnement de l'environnement migré :

  1. Ouvrir le Portail d'entreprise (Company Portal)
  2. Réinstaller Netskope et se connecter
  3. Vérifier le bon fonctionnement de :
    • Okta
    • Microsoft Teams
    • Office 365
13

Synchronisation Intune

Forcer la synchronisation du poste avec Intune pour appliquer les politiques :

  1. Aller dans : Paramètres → Accès professionnel ou scolaire → Compte → Informations
  2. Cliquer sur Synchroniser
14

Reconnexion des imprimantes et lecteurs réseau

Reconnecter les ressources réseau de l'utilisateur :

  • Imprimantes via : \\FR1MS01.supervadnet.com
  • Lecteurs réseau via :
    • \\FR1FPS01.supervadnet.com
    • \\FR1FPS02.supervadnet.com
    • \\FR1FPS03.supervadnet.com

Checklist de validation

Points de validation post-migration
  • Données utilisateur sauvegardées (favoris Chrome, OneDrive)
  • Netskope désinstallé et dossier C:\Intune présent
  • Compte Magic ajouté au groupe Administrateurs
  • Poste sorti du domaine et redémarré
  • Poste joint à Entra ID depuis la session Magic
  • Migration du profil effectuée via Profwiz (Azure AD coché)
  • Company Portal accessible et Netskope réinstallé
  • Okta, Teams et Office 365 fonctionnels
  • Synchronisation Intune effectuée
  • Imprimantes et lecteurs réseau reconnectés
